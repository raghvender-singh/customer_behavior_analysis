# Customer Shopping Behavior Analysis

An end-to-end data analytics project using Python, MySQL, Power BI, and Gamma to analyze customer purchasing patterns and generate actionable business insights.

## 📌 Project Overview

This project analyzes customer shopping behavior using a dataset containing 3,900 purchase records across multiple product categories.

The objective is to understand customer spending patterns, product preferences, discount usage, customer loyalty, and subscription behavior to support data-driven business decisions.

The project covers the complete analytics workflow, including data loading, exploratory data analysis (EDA), data cleaning, feature engineering, SQL-based business analysis, interactive dashboard development, report preparation, and presentation creation.

## 📊 Dataset

**Dataset:** Customer Shopping Behavior

- **Total Records:** 3,900
- **Total Columns:** 18
- **Missing Values:** 37 in the review rating column

### Key Features

| Category | Features |
|---|---|
| Customer Demographics | Age, Gender, Location, Subscription Status |
| Purchase Details | Item Purchased, Category, Purchase Amount, Season, Size, Color |
| Shopping Behavior | Discount Applied, Promo Code Used, Previous Purchases, Frequency of Purchases |
| Customer Experience | Review Rating, Shipping Type |

## 🔄 Project Workflow

### 1. Data Loading and Exploratory Data Analysis

Loaded the customer shopping dataset into Python using Pandas and examined its structure, quality, and statistical characteristics.

Key activities:
- Inspected dataset structure and data types using `df.info()`.
- Generated descriptive statistics using `df.describe()`.
- Examined missing values and data consistency.
- Explored customer demographics, purchasing behavior, and product preferences.

### 2. Data Cleaning and Feature Engineering

Prepared the dataset for analysis by improving data consistency and creating additional analytical features.

Key activities:
- Handled 37 missing values in the `review_rating` column using the median rating of the corresponding product category.
- Standardized column names using snake_case.
- Created an `age_group` column to categorize customers by age.
- Created a `purchase_frequency_days` column to represent purchase frequency numerically.
- Checked for redundancy between `discount_applied` and `promo_code_used` and removed the redundant column.
- Prepared the cleaned dataset for database analysis.

### 3. SQL Analysis Using MySQL

Used SQL queries to investigate customer purchasing patterns and answer important business questions.

The analysis covered:

1. **Revenue by Gender** — Compared total revenue generated by male and female customers.
2. **High-Spending Discount Users** — Identified customers who used discounts but spent above the average purchase amount.
3. **Top 5 Products by Rating** — Identified products with the highest average review ratings.
4. **Shipping Type Comparison** — Compared average purchase amounts for Standard and Express shipping.
5. **Subscribers vs. Non-Subscribers** — Compared customer counts, average spending, and total revenue by subscription status.
6. **Discount-Dependent Products** — Identified products with the highest percentage of discounted purchases.
7. **Customer Segmentation** — Classified customers into New, Returning, and Loyal segments based on purchase history.
8. **Top Products by Category** — Identified the most purchased products within each category.
9. **Repeat Buyers and Subscriptions** — Examined subscription status among customers with more than five purchases.
10. **Revenue by Age Group** — Calculated revenue contribution across different age groups.

### 4. Power BI Dashboard

Developed an interactive Power BI dashboard to present key performance indicators and customer shopping insights.

**Dashboard highlights:**
- Total number of customers
- Average purchase amount
- Average review rating
- Customer distribution by subscription status
- Revenue by product category
- Sales by product category
- Revenue by age group
- Sales by age group
- Interactive filters for subscription status, gender, category, and shipping type

The dashboard provides a consolidated view of customer behavior and helps identify patterns in purchasing activity, revenue contribution, and customer demographics.

The following findings were obtained from the analysis documented in the project report.

| Analysis Area | Key Finding |
|---|---|
| Revenue by Gender | Male customers generated 157,890 in revenue, compared with 75,191 from female customers. |
| Subscription Behavior | Non-subscribers generated 170,436 in total revenue, while subscribers generated 62,645. |
| Average Purchase Amount | Subscribers spent an average of 59.49, compared with 59.87 for non-subscribers. |
| Shipping Type | Express shipping customers had an average purchase amount of 60.48, compared with 58.46 for Standard shipping. |
| Customer Segmentation | 3,116 Loyal customers, 701 Returning customers, and 83 New customers were identified. |
| Product Ratings | Gloves had the highest average rating among the top five products, at 3.86. |
| Discount Usage | Hats had the highest discounted-purchase rate at 50%, followed by Sneakers at 49.66%. |
| Revenue by Age Group | Young Adults contributed the highest revenue at 62,143, followed by Middle-aged customers at 59,197. |

*Monetary values are reported in the dataset's monetary units.*

## 💡 Business Recommendations

Based on the analysis, the following recommendations were developed:

- **Boost Subscriptions:** Promote exclusive benefits to encourage more customers to subscribe.
- **Strengthen Customer Loyalty:** Introduce loyalty programs and rewards for repeat buyers.
- **Review Discount Policies:** Evaluate the effectiveness of discounts while maintaining control over profit margins.
- **Improve Product Positioning:** Highlight highly rated and best-selling products in marketing campaigns.
- **Targeted Marketing:** Focus marketing efforts on high-revenue age groups and evaluate purchasing behavior across shipping types.

## 🚀 How to Run the Project

### Prerequisites

- Python 3
- MySQL Server and MySQL Workbench
- Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://github.com/raghvender-singh/customer_behavior_analysis.git
cd customer_behavior_analysis
```

### Step 2: Install Python Libraries

```bash
pip install pandas matplotlib seaborn sqlalchemy pymysql
```

### Step 3: Run the Python Script

```bash
python customer_shopping_behavior_analysis.py
```

Ensure that the dataset is available at the file path configured in the Python script.

### Step 4: Run the SQL Queries

1. Open MySQL Workbench and connect to your MySQL server.
2. Open `customer_behavior_sql_queries.sql`.
3. Select the database containing the customer shopping data.
4. Execute the queries to reproduce the business analysis.

Ensure that the required table exists and that its column names match those used in the SQL queries.

### Step 5: Open the Power BI Dashboard

Open `customer_behavior_dashboard.pbix` in Power BI Desktop.

Refresh the data source and update the connection settings if required.

### Step 6: Review the Presentation and Report

Open `Customer-Shopping-Behavior-Analysis.pptx` to review the project presentation. Refer to the project report for the detailed methodology, analysis, and business recommendations.
